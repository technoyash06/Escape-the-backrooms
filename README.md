# Shiftbreaker code map

- `index.html` — the small launcher page. It loads the files below in the correct order.
- `styles/shiftbreaker.css` — menu and page appearance.
- `scripts/shiftbreaker-assets.js` — supplied image paths and image crop measurements.
- `scripts/shiftbreaker-data.js` — the three player forms and six level descriptions.
- `scripts/shiftbreaker-game.js` — controls, movement, puzzles, enemies, HUD, sound, and drawing.

Open `index.html` to play. The script order in the HTML file must stay the same.
